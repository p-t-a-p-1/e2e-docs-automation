# MVP受け入れ条件 — ローカル版

品質条件の正本。フェーズ毎に対応するIDを確認する。

| ID | 条件 | フェーズ |
|---|---|---|
| AC-01 | pnpm workspaces + Turborepoが動作し、`workspace:*`で内部依存を解決する | PH-01 |
| AC-02 | Vite+でReact SPAが起動・ビルドし、`vp check`のOxlint/Oxfmt/型検査が通る | PH-01,02 |
| AC-03 | APP-01〜07が動作し、localStorageから再読み込みで復元する | PH-02 |
| AC-04 | e2eの6シナリオを実行し、各アサーションで合否を確認する | PH-03 |
| AC-05 | 指定ステップで画像を取得し、レポートと紐付く | PH-03,04 |
| AC-06 | e2e JSONを正規化し、失敗/skipを成功に変換しない | PH-04 |
| AC-07 | 成功シナリオのマニュアルMDXと品質レポートが生成される | PH-04 |
| AC-08 | Blumeでマニュアル・品質結果・画像を検索・閲覧できる | PH-05 |
| AC-09 | Blumeビルド成功、リンク/画像欠損ゼロ | PH-05 |
| AC-10 | `pnpm docs:sync`でローカル一括実行が最後まで完走する | PH-06 |
| AC-11 | 必須テスト失敗時は非ゼロ終了、前回正常生成物を保持し、診断出力が残る | PH-06 |
| AC-12 | UI変更後の再実行で対象画面画像と検証日時が更新される | PH-06 |

## 定量目標
6シナリオ自動実行、対象マニュアル100%自動生成、手動撮影0回、手動MDX編集0回。6シナリオ実行10分以内は参考目標であり保証値ではない。

## リリース判定
AC-01〜AC-12の全件合格。CI/CD・自動デプロイはMVP完成条件に含まない。
