# 品質レポート生成 — 機能仕様

**関連:** PH-04, PH-05 / **要件:** FR-05

## 内容
- runId、実行日時、Git SHA（取得可能な場合）、対象アプリ、テスト環境。
- 総件数/成功/失敗/スキップ/成功率と分母の定義。
- 各シナリオのID・タイトル・状態・時間・アサーション・証跡。

## ローカル生成ポリシー
- Blumeの `/quality/latest` は**最後に正常検証されたrun**を示す。
- 失敗runの詳細は `.artifacts/e2e/<runId>/` に残し、latestを置換しない。
- 失敗レポートはローカルで読めるようにし、公開候補ページには混ぜない。
- パス、秘密情報、個人情報の露出を避ける。

## 出力
`apps/docs/docs/quality/latest.mdx` と `apps/docs/docs/quality/tests/<slug>.mdx`。

## 合格条件
集計件数が一致し、skip/failedを成功率に算入しない。コミット不明なら未取得と表示。
