# 操作マニュアル自動生成 — 機能仕様

**関連:** PH-04, PH-07 | **要件:** FR-04

## 入力
- 正規化された成功シナリオの実行証跡
- `packages/scenarios` のシナリオ正本（操作目的、前提条件、ステップの説明、期待結果、必須画像ラベル）

## 生成内容
- タイトル、操作目的、前提条件、番号付き手順
- 手順に対応するスクリーンショットと代替テキスト
- 最終的に確認できた期待結果
- シナリオID、実行日時、Git SHA、検証済みの状態

## 出力ページ
`apps/docs/docs/manuals/<scenario-slug>.mdx`（操作マニュアル）

## 安全・整合性
- 失敗/スキップされたシナリオは「検証済み」として生成・公開しない。
- テンプレート方式で決定的に生成するのをデフォルトとする。
- AIで読みやすく書き換える場合も、ステップの追加・削除・順序変更・未検証動作の断定は禁止する。
- 画像・stepIdが紐付かない場合、作ったことにせず検証エラーとする。
- 同一runの再生成は同じ内容になる（時刻やURLなどの入力が同じなら差分ゼロ）。

## 合格条件
必要な手順と画像を含む日本語MDXが生成されること。frontmatter・リンク・画像パスが検証に通ること。テンプレート方式だけでAI文章生成APIなしでも完走できること。
