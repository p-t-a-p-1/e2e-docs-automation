# プロダクト概要（Level 1）

## 目的
**E2Eテストで確認した実際の操作を根拠として、操作マニュアルと品質レポートを自動生成する。** 手動撮影やMDX編集なしに、ローカルの1コマンドで最新ドキュメントを得られるPoCを構築する。

## 対象ユーザー
Web開発者、QA、文書担当、操作方法を確認するユーザー。

## デモで成立させる体験
1. **Vite+ / React / TypeScript** のTaskFlowアプリで操作できる。
2. e2eで自然言語操作・明示的アサーション・必要な証跡を記録できる。
3. `packages/docgen` で証跡を検証して操作マニュアル/品質レポートのMDXを生成できる。
4. Blumeで検索可能なドキュメントサイトをローカルビルド/プレビューできる。
5. `pnpm docs:sync` を実行すると2〜4が連続して動く。エラー時は非ゼロ終了し、最後の正常ドキュメントを壊さない。

## MVPスコープ
- **pnpm workspaces + Turborepo** のモノレポと **Vite+** の開発ツールチェーン。
- TaskFlow: 追加・編集・完了切替・削除・localStorage永続化・入力検証。
- e2eの必須6シナリオとスクリーンショット/JSON/HTMLレポート。
- 検証済み手順のマニュアル、品質レポート、Blumeサイト。
- ローカル一括実行と実行履歴の保存、異常時のフェイルクローズ。

## 非対象（今回）
GitHub Actions/その他CI、Pushをトリガーにした更新、Cloudflare Pagesへの自動公開、外部DB、認証、VRT、未検証手順のAI自動作成、翻訳、複数サービス統合。

## 重要制約
- 操作手順・期待結果はレビュー可能な `scenarios/` を正本とし、AIの推測を採用しない。
- 必須テストの失敗・スキップ・画像欠落を成功扱いしない。
- 実行証跡・診断レポートはローカル `.artifacts/` に残し、Secretsや個人情報をサイト出力しない。
- e2eの出力スキーマはAdapterで吸収し、採用バージョンを固定する。
- モノレポタスクはTurborepo、アプリ固有タスクはVite+に分担する。
